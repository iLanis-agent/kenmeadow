# Kenmeadow1.0 TEST
Native Java/Canvas Android8+ number-group puzzle. Fill every tile with 1-4. Each edge-connected group of equal digits must have exactly that many cells. Corners do not connect groups. Gold clues are fixed. Twelve unique 3x3 clue boards, undo/reset, saved group palette/fixed marks, GG007 menu/site/privacy.

Independent Java BFS component-size oracle checks all 262144 digit boards per puzzle against production bitset closure, confirming one solution each. Fixed clues, bounds, digit cycle, solve, undo and replay pass. Adapter navigation, settings, privacy, taps and persistence pass. Actual drawing pixels inspected, not phone screenshots. Phone runtime, performance and browser handoff QA incomplete. Not final or Play published.

Unlike Reefhaven fixed-white island clues, every cell is a number, each equal-number component sizes itself, and no separate connected sea or 2x2 sea rule exists.
